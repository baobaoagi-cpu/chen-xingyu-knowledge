# 陳星語的公開知識庫

這是陳星語累積資訊安全、業務情報判讀、產品與戰略管理方法的公開工作筆記。內容是可重用的方法與公開來源索引，不代表任何公司的內部決策、正式風險評估或已完成驗收。

## 分類

| 路徑 | 內容 |
| --- | --- |
| [security/](security/README.md) | 漏洞應對、服務盤點、發版驗證與安全習慣 |
| [intelligence/](intelligence/README.md) | 公開情報的來源、可信度與時效判讀 |
| [strategy/](strategy/README.md) | 決策紀錄、風險清單與服務治理模板 |
| [methods/](methods/README.md) | 經驗復盤及方法演進 |

## 使用原則

1. 將「來源陳述、獨立核驗、推論、決策、執行、驗收」分開記錄。
2. 每個時效性結論標日期與原始公開來源；過期時重新核對。
3. 公開庫只收公開資料與去識別的方法。公司群組對話、客戶資料、憑證、內部網址、成本與未公開策略不進此庫。
4. 若需管理內部情報，使用另行授權的私有系統；公開文件只保留通用模板。

目前以 Markdown 和 Git 追蹤版本。只有當實際檢索需求超過檔案與 Git 搜尋能力時，才評估向量或圖資料庫。
