# 資訊安全

## 工具與流程

- [漏洞事件卡](vulnerability-response.md)：把公告對應到實際服務、版本與暴露條件。
- [發版證據鏈](release-evidence.md)：區分修補候選、測試、正式部署與驗收。

安全警報的優先順序應依正式環境是否命中、暴露面、利用條件與已知實際利用調整。公開漏洞公告是調查起點，不是某個產品受影響的證據。

常用公開來源：[CISA KEV](https://www.cisa.gov/known-exploited-vulnerabilities-catalog)、[GitHub Advisory Database](https://github.com/advisories)、[OSV](https://osv.dev/)、供應商官方安全公告。使用時核對公告更新日期與修補版本。
